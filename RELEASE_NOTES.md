# PVPSE Client v1.3.1

Crosshair editor scrolling fix for Fabric 1.21.11 and Java 21.

## Fixed

- The crosshair drawer now scrolls vertically with the mouse wheel
- A visible scrollbar shows the current position
- Drawing controls, palette, copy/paste buttons, and reset controls remain reachable on smaller screens

## Included

- Damage tilt 0, combo HUD, reach HUD, and low-health alerts
- Scrollable main ClickGUI
- Custom themes and HUD editor
- Crosshair design import/export
