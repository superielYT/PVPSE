# PVPSE Client v1.4.0

Utility modules release for Fabric 1.21.11 and Java 21.

## New modules

- **Waypoint:** press B to save your position; the movable HUD shows distance and coordinates
- **Zoom:** hold Z, with an adjustable FOV slider
- **No Pumpkin:** removes the carved-pumpkin overlay while enabled
- **Fullbright:** toggle with V, with an adjustable brightness slider

## Settings system

- Left-click a module to enable or disable it
- Right-click a module to expand its own settings
- Zoom and Fullbright have module-specific sliders
- Waypoint has visibility and HUD-scale controls
- Values and enabled states are saved in configuration profiles

## Included

- Crosshair editor scrolling and design sharing
- Damage tilt 0, combo HUD, reach HUD, and low-health alerts
- Custom themes, draggable HUD editor, and main ClickGUI scrolling
